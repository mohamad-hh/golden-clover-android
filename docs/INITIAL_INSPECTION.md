# Clover Inferno demo implementation scope

The requested cabinet screenshot matches Clover Inferno in APEX Clover Link Elements. The APEX Elements brochure shows the same three trees and red fire theme and describes Blaze, Jackpot and Bomb. Indexed Novomatic Spain information identifies 5 reels, 25 lines and Grand / Major / Maxi / Minor / Mini; Grand and Major are progressives.

The pre-existing repository implemented a different landscape Golden Clover garden, 1,000 virtual TL, seven lines and a single hold-and-respin feature. The new implementation uses portrait English UI, virtual dollars, $2,000 foreground sessions, 25 lines, wild BAR, three combinable feature types and a double board for Jackpot.

The commercial probability weights and exact paytable were not obtainable from the reviewed sources. The user authorized independent probabilities. The mathematics, 3-respin counter, trigger threshold, rectangular Bomb selection and free preview chooser are explicitly custom demo choices. All seven feature combinations can occur in paid demo play.

Game graphics and audio are independent assets. No commercial game binaries, original cabinet screenshots or extracted commercial audio ship in the APK. The app has no network or payment permissions.
